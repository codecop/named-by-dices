## api_push.py

Push von lokalen Commits auf den Remote-Branch über die GitHub-REST-API.

**Warum:** Im Cloud-Sandbox ist `git push` (smart-HTTP receive-pack) durch den
Sandbox-Proxy blockiert (403), die REST-API (api.github.com) ist aber erlaubt.
**Wo gebraucht:** nur in der Cloud-Instanz. Lokal/normal funktioniert
`git push origin <branch>`.

**Datenquellen:** Token aus `API_PUSH_TOKEN` (Env), `~/.push-token`
(`chmod 600`, nie committen!) oder `gh auth token`. Repo kommt aus
`git remote get-url origin`. Siehe auch `.agents/skills/commit/SKILL.md`.

**Verwendung in neuer Session:**

```
gh repo clone <owner>/<repo>
echo '<token-mit-repo-write>' > ~/.push-token && chmod 600 ~/.push-token
git add -A && git commit -m "<msg>

Generated by Mistral Vibe.
Co-Authored-By: Mistral Vibe <vibe@mistral.ai>"
python3 scripts/api_push.py
```
